# 🎮 NEXUS ARCADE // 800+ Free Playable HTML5 Games

A high-speed cyber-arcade gaming portal with 800+ playable browser games powered by the 100% Free Open GameDistribution Syndication API.

## 🚀 Features
- **800+ HTML5 Games**: Instant-play across Racing, Action, Sports, Puzzle, Strategy, Shooter, Casual, Adventure.
- **Zero Install / Zero Lag**: Embeds directly with responsive HTML5 players.
- **Live Search & Category Filters**: Search games in real time by title or tag.
- **Favorites & Bookmarks**: Save favorite games locally.
- **Cinema-Grade Modal Player**: Fullscreen, restart, and game control drawer.
- **Free of Cost**: Open public syndication API with zero subscriptions or fees.

Click the **Deploy to Render** button above, or open:

### Option 2: Manual Setup on Render Dashboard
1. Log in to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** -> **Static Site**.
3. Connect your GitHub repository: `aklove4047-cpu/nexus-arcade`.
4. Leave **Build Command** empty.
5. Set **Publish Directory** to `./` (Render will serve `index.html`).
6. Click **Create Static Site** — your live URL will be ready in seconds!
